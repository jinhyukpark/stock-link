## 1. 인터랙션 제거 — 모든 콘텐츠 즉시 노출

Remove ALL click-to-expand, accordion, dropdown, and modal interactions.
Every piece of information must be visible on page load with zero user effort.

**제거 대상:**
- 테이블 행 클릭 시 펼쳐지는 아코디언 상세 패널 → 완전 제거
- 날짜 선택 드롭다운 → 상단에 날짜 탭 버튼 형태로 교체
  (예: [04/24] [04/25] [04/26 ●] 형태의 pill 탭, 기본값 = 오늘)
- 기타 클릭 없이는 볼 수 없는 콘텐츠 일체 제거

**대신 가독성 유지 방법:**
- 각 섹션 간 충분한 여백 (`mb-16`)
- 섹션 타이틀에 굵은 구분선 (`border-t-2 border-slate-600 pt-6 mb-6`)
- 카드/행 간 `gap-3` 이상 확보
- 발언 요약 텍스트: 최대 3줄, `line-clamp-3` 적용 후 전체 텍스트를 tooltip 없이 그냥 3줄로 표시 (말줄임 허용)
