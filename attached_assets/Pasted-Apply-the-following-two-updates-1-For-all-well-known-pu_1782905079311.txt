## 1. 주요 인물 아바타 — 실제 이미지 적용

For all well-known public figures, load real portrait photos from Wikipedia Commons.
Do NOT use drawn illustrations or AI-generated images — use the direct Wikipedia CDN URLs below.

```jsx
const influencerAvatars = {
  '일론 머스크':
    'https://upload.wikimedia.org/wikipedia/commons/thumb/3/34/Elon_Musk_Royal_Society_%28crop2%29.jpg/240px-Elon_Musk_Royal_Society_%28crop2%29.jpg',
  '도널드 트럼프':
    'https://upload.wikimedia.org/wikipedia/commons/thumb/5/56/Donald_Trump_official_portrait.jpg/240px-Donald_Trump_official_portrait.jpg',
  '이창용':
    'https://upload.wikimedia.org/wikipedia/commons/thumb/4/4e/Chang_Yong_Rhee_%28cropped%29.jpg/240px-Chang_Yong_Rhee_%28cropped%29.jpg',
  '짐 크레이머':
    'https://upload.wikimedia.org/wikipedia/commons/thumb/e/e1/Jim_Cramer_2012_Shankbone.jpg/240px-Jim_Cramer_2012_Shankbone.jpg',
  '워런 버핏':
    'https://upload.wikimedia.org/wikipedia/commons/thumb/5/51/Warren_Buffett_KU_Visit.jpg/240px-Warren_Buffett_KU_Visit.jpg',
  '레이 달리오':

  '제롬 파월':
    'https://upload.wikimedia.org/wikipedia/commons/thumb/8/8e/Jerome_H._Powell%2C_Governor%2C_Federal_Reserve_Board_of_Governors_%28cropped%29.jpg/240px-Jerome_H._Powell%2C_Governor%2C_Federal_Reserve_Board_of_Governors_%28cropped%29.jpg',
};
```

**아바타 렌더링 컴포넌트:**
```jsx
const Avatar = ({ name }) => {
  const src = influencerAvatars[name];
  const initials = name.replace(/\s/g, '').slice(0, 2);

  return (
    <div className="relative w-10 h-10 flex-shrink-0">
      {src && (
        <img
          src={src}
          alt={name}
          className="w-10 h-10 rounded-full object-cover object-top
            border-2 border-slate-600 shadow-md"
          onError={(e) => {
            e.currentTarget.style.display = 'none';
            e.currentTarget.nextSibling.style.display = 'flex';
          }}
        />
      )}
      <div
        style={{ display: src ? 'none' : 'flex' }}
        className="w-10 h-10 rounded-full bg-slate-600 border-2 border-slate-500
          items-center justify-center text-white text-sm font-bold shadow-md
          absolute inset-0"
      >
        {initials}
      </div>
    </div>
  );
};
```

**국내 알 수 없는 인물 (유튜버, 블로거 등):**
- 이니셜 배지 자동 적용
- `bg-slate-700 border-2 border-slate-600`

## 2. 방향 아이콘 컴포넌트 — 한 줄 고정 + 사이즈 축소

The direction indicator in 시장 영향 분석 방향 column is currently
too tall and multi-line. Compress into a compact single-line format.

**핵심 원칙:**
- 방향 아이콘 전체가 `whitespace-nowrap` 한 줄에 들어와야 함
- 레이블 텍스트("소폭 수혜" 등)와 아이콘이 가로로 나란히 배치
- 세로 바 차트 제거 — 텍스트 + 화살표 SVG 아이콘만 사용
- 컬럼 너비: `w-24` 고정

**방향별 컴포넌트 (전면 교체):**
```jsx
const DirectionBadge = ({ type }) => {
  const config = {
    '수혜':       { icon: '▲', label: '수혜',    color: '#34d399', bg: 'rgba(52,211,153,0.1)'  },
    '소폭수혜':   { icon: '↗', label: '소폭수혜', color: '#34d399', bg: 'rgba(52,211,153,0.07)' },
    '관망':       { icon: '─', label: '관망',    color: '#94a3b8', bg: 'rgba(148,163,184,0.1)' },
    '소폭리스크': { icon: '↘', label: '소폭리스크', color: '#ff7c7e', bg: 'rgba(255,124,126,0.07)' },
    '리스크':     { icon: '▼', label: '리스크',  color: '#ff7c7e', bg: 'rgba(255,124,126,0.1)' },
  };

  const c = config[type] ?? config['관망'];

  return (
    <div
      className="inline-flex items-center gap-1 px-2 py-1 rounded-md
        whitespace-nowrap text-xs font-semibold"
      style={{ color: c.color, backgroundColor: c.bg }}
    >
      <span className="text-sm leading-none">{c.icon}</span>
      <span className="leading-none">{c.label}</span>
    </div>
  );
};
```

**적용 결과 (한 줄 예시):**
- `▲ 수혜` — emerald tint pill
- `↗ 소폭수혜` — lighter emerald tint pill (한 줄, 절대 줄바꿈 없음)
- `─ 관망` — slate tint pill
- `↘ 소폭리스크` — lighter pink tint pill
- `▼ 리스크` — pink tint pill

**제거할 것:**
- 세로 방향 바 차트 (막대그래프 아이콘) 전체 제거
- 아이콘과 텍스트가 세로로 쌓이는 레이아웃 전체 제거
- 방향 셀 내 `flex-col` 구조 전체 제거 → `inline-flex items-center`로 교체
