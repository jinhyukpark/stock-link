## 3. 긍정/부정 색상 모호함 제거

In a Korean stock service, red = price up and blue = price down.
Using red for 부정 sentiment creates confusion. Redesign as follows:

**변경 후 색상 컨벤션:**

| 구분 | 기존 | 변경 후 |
|------|------|---------|
| 호재 (긍정) | green | `#34d399` emerald-400 — 유지 |
| 악재 (부정) | red | `#fb923c` orange-400 |
| 중립 | gray | `#94a3b8` slate-400 — 유지 |

- Replace ALL instances of red (`red-400`, `red-500`, `red-900`) used for 부정/악재 sentiment with orange (`orange-400`, `orange-500`, `orange-900`)
- This applies to: 시장 영향도 badges, 종목 카드 accents, 하이라이트 negative keywords, sector summary text
- Stock price movement colors (상승/하락 arrows in sector summary) remain:
  - ↑ 상승: `text-red-400` (주가 상승 = 빨강, 한국 증시 컨벤션 유지)
  - ↓ 하락: `text-blue-400`
  - ↗ 소폭 상승: `text-red-400`
  - ↘ 소폭 하락: `text-blue-400`
  - → 중립: `text-slate-400`
- This way, red strictly means "price going up" and orange means "negative sentiment/news" — no overlap

**Badge 변경:**
- 호재: `bg-emerald-500 text-white`
- 악재: `bg-orange-500 text-white`
- 중립: `bg-slate-500 text-white`
